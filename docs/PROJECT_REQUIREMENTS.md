# 综合域名、静态网站与软件分发平台需求说明

版本：1.0  
状态：已确认，后续开发基线  

## 1. 产品定位

本项目是一个综合管理平台，不是单纯的软件下载站。平台必须提供三项彼此独立、又可组合使用的核心能力：

1. 多域名跳转管理；
2. 静态网站上传、发布和域名绑定；
3. 软件、版本和安装包分发。

所有来源域名、目标网址、网站文件、软件资料和下载地址必须在管理后台动态配置，禁止写死在前端或后端代码中。

## 2. 系统组成

```text
综合管理平台
├── 平台公开首页
├── 管理后台
├── 域名接入与跳转服务
├── 静态网站托管服务
├── 软件和版本管理服务
├── 安装包对象存储与下载服务
├── 数据统计服务
└── 安全与审计服务
```

## 3. 用户与权限

### 3.1 第一阶段角色

- 超级管理员：拥有全部管理权限。
- 普通访问者：访问公开页面、跳转域名、静态网站和下载内容。

### 3.2 后续可扩展角色

- 域名管理员
- 网站内容管理员
- 软件与文件管理员
- 数据查看员
- 只读管理员

第一阶段的数据模型和权限校验不得阻碍后续增加角色。

## 4. 域名跳转系统

域名跳转是独立核心业务，不得只实现为下载链接跳转。

### 4.1 管理字段

管理员必须能够配置：

- 来源域名；
- 目标地址；
- 规则名称；
- 用途和备注；
- `301` 或 `302`；
- 是否启用；
- 生效时间和失效时间；
- 是否强制 HTTPS；
- 是否保留原路径；
- 是否保留查询参数；
- 自定义维护页；
- 规则优先级。

### 4.2 允许的跳转目标

目标可以是任何通过安全校验的网页，包括但不限于：

- 表白网页；
- 活动落地页；
- 企业官网；
- 婚礼邀请页；
- 产品介绍页；
- 个人主页；
- 商城和客服页面；
- 第三方网站；
- 平台内部静态网站；
- 软件详情页；
- 安装包下载地址。

### 4.3 域名运行模式

每个域名必须可以独立选择：

1. 跳转到外部网址；
2. 直接展示平台内部静态网站；
3. 跳转到软件详情页或下载页；
4. 显示自定义维护页；
5. 暂停访问。

### 4.4 路径规则

必须支持：

- 根域名整体跳转；
- 所有路径统一跳转到一个目标；
- 保留原始路径；
- 保留或丢弃查询参数；
- 单独路径规则；
- 根域名、`www` 和其他子域名；
- 规则冲突检测；
- 跳转循环检测。

### 4.5 访问语义说明

- 用户在浏览器地址栏输入域名并访问时，可以跳转或展示指定网页。
- 用户在搜索引擎中点击该域名的搜索结果后，可以跳转。
- 用户只在搜索引擎输入关键词、但没有点击结果时，平台无法控制搜索引擎强制跳转。

## 5. 域名接入

### 5.1 接入流程

```text
后台添加域名
→ 展示 DNS 配置说明
→ 验证域名所有权和 DNS
→ 申请或绑定 HTTPS 证书
→ 启用跳转或静态网站
```

### 5.2 状态

后台必须显示：

- 等待 DNS 配置；
- DNS 验证中；
- DNS 配置错误；
- HTTPS 证书申请中；
- 正常运行；
- 证书异常；
- 已暂停；
- 已过期。

### 5.3 安全约束

- 域名必须由管理员或客户合法拥有并完成验证。
- 禁止未验证域名正式启用。
- 禁止 `javascript:`、`data:` 等危险跳转协议。
- 目标 URL 必须进行规范化和合法性检查。

## 6. 静态网站管理

### 6.1 使用场景

- 表白网页
- 企业官网
- 活动页面
- 婚礼邀请页
- 个人主页
- 产品展示页
- 软件官网
- 帮助文档

### 6.2 必须功能

- 创建、编辑和删除网站项目；
- 上传 HTML、CSS、JavaScript 和资源文件；
- 上传完整 ZIP 包；
- 安全解压并检查路径穿越；
- 识别或指定首页文件；
- 在线预览；
- 发布和下线；
- 管理图片、字体、音频等资源；
- 自定义 404 页面；
- 发布记录；
- 历史版本回滚；
- 绑定一个或多个自定义域名；
- 生成平台内部预览地址；
- 查看访问统计。

### 6.3 绑定行为

域名绑定内部静态网站时，浏览器地址栏应保持访问域名不变，不得强制跳到平台主域名。

### 7.2 支持维度

### 7.3 后台功能

## 8. 对象存储与 CDN

### 8.1 强制架构原则

- 安装包和大型静态资源必须进入对象存储。
- 管理员浏览器应直接上传到对象存储，业务服务器只签发上传授权和保存元数据。
- 下载者应直接从对象存储或 CDN 下载，业务服务器不得代理大文件流量。
- 存储服务必须抽象，不能把业务锁死在一个厂商 SDK 中。

### 8.2 可接入服务

- Cloudflare R2；
- 阿里云 OSS；
- 腾讯云 COS；
- 其他 S3 兼容对象存储。

### 8.3 CDN

- CDN 是可配置能力，不是第一阶段必须购买的固定服务。
- 下载量较小时允许对象存储直出。
- 启用 CDN 后需要支持缓存规则、回源、安全链接和流量监控。

```text
管理后台
├── 登录
├── 仪表盘
├── 域名管理
├── 跳转规则
├── 静态网站
├── 网站文件与发布记录
├── 软件管理
├── 版本管理
├── 安装包管理
├── 对象存储
├── 数据统计
├── 公告管理
├── 操作日志

└── 系统设置
```

### 9.1 仪表盘

必须展示：

- 域名总数和运行状态；
- 静态网站数量；
- 软件和安装包数量；
- 今日访问、跳转和下载量；
- 访问趋势；
- 最近活动；
- 存储空间使用情况；
- 需要管理员处理的异常状态。

## 10. 数据统计

### 10.1 域名与跳转

- 总访问量和今日访问量；
- 最近访问时间；
- 日、周、月趋势；
- 域名排行；
- 每条规则跳转次数；
- 跳转成功和失败次数；
- 目标页面排行。

### 10.2 静态网站

- 页面访问量；
- 网站排行；
- 来源页面；
- 设备和浏览器类型。

### 10.3 下载

- 软件总下载量；
- 版本、平台和架构下载量；
- 热门软件排行；
- 每日下载趋势。

### 10.4 隐私

优先保存汇总统计，不长期保存完整访问者 IP；日志保存周期和脱敏方式必须可配置。

## 11. 安全要求

- 密码使用安全哈希算法保存；
- 登录失败限制和速率限制；
- 会话过期和主动退出；
- 服务端权限校验；
- CSRF、XSS、SQL 注入和开放重定向防护；
- 域名所有权验证；
- 上传扩展名、MIME 和文件头检查；
- 上传大小限制；
- ZIP 解压路径穿越防护；
- 文件哈希校验；
- 可选病毒扫描；
- 防盗链和签名下载地址；
- 关键操作二次确认；
- 管理员操作日志；
- 数据库和对象文件备份；
- 流量、存储或费用异常预警。

## 12. 响应式和兼容性

- 支持桌面、笔记本、平板和手机；
- 支持鼠标、键盘和触摸；
- 手机端表格应转换成卡片或提供合理的横向查看方式；
- 表单和按钮需要满足移动端触摸尺寸；
- 兼容主流现代浏览器；
- 支持明暗模式和系统主题；
- 支持 `prefers-reduced-motion`。

## 14. 非目标与边界

第一阶段默认不包含：

- 付费购买和支付系统；
- 面向公众的用户注册体系；
- 在线可视化拖拽建站器；
- 搜索引擎未点击情况下的强制跳转；
- 大型视频流媒体服务；
- 未经所有权验证的域名接入。

这些能力只能作为后续独立需求加入。

## 15. 验收原则

- 任意合法来源域名和目标地址可从后台添加，不修改代码即可生效。
- 域名可独立选择“外部跳转”或“内部静态网站”。
- 静态网站可上传、预览、发布、绑定域名和回滚。
- 软件可管理多个版本、平台、架构和安装包。
- 大文件上传和下载不经过普通业务服务器。
- 管理后台能清晰查看状态、统计和异常。
- 所有页面符合 `UI_DESIGN_SYSTEM.md`，并通过浅色、深色、桌面和移动端检查。
